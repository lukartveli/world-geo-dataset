# Data format



## ADM0

Countries currently contain:
1. English name
2. Official full English name
3. Iso 3166-1 alpha-2
4. Iso 3166-1 alpha-3
5. International Status



## Administrative Hierarchy

The dataset follows these principles when determining administrative
subdivisions and hierarchy:

1. International recognition
2. National constitution and legal framework
3. De facto control and territorial division
4. Project judgment where ambiguity remains

The dataset prioritizes consistency and usefulness for geographic
learning over adherence to any single external administrative database.
